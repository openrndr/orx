Transitions

class Transitions<V>(interpolate: (property: String, a: V, b: V, t: Double) -> V)(source)

The transitions of the properties of one element, of values of type V that interpolate interpolates: a change of a property with a TransitionTiming transitions from the value that is shown, also when another transition of the property runs, to the new value. Transitions of CSS.

Parameters

interpolate

the value of property between a and b at t, from 0 to 1
