HashBlur

class HashBlur : ShadeStyleFilter1to1(source)

Hash blur, based on Hashed blur by David Hoskins.

Every pixel averages samples randomly placed samples from a disc with radius radius², optionally spread out along a line in direction over spread pixels. The radius scale and the direction are presets that can vary per pixel, for example by reading them from textures:

blur.radiusScale = TextureScalar(radiusMap)       // multiplies by the red channel
blur.direction = TextureVector2(directionMap)     // reads the red and green channels

Replacing a preset with one of the same class does not recompile the shader.
