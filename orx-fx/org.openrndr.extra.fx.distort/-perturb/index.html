Perturb

class Perturb : ShadeStyleFilter1to1(source)

Distorts its input by displacing texture coordinates with a warp preset.

The warp maps a texture coordinate, with offset and segmentation applied, to the coordinate to read from; the difference is the displacement. By default it is a NoiseWarp, fractal simplex noise. Assigning a warp of another class compiles a shader once per class; changing the properties of a warp does not recompile.

val noise = NoiseWarp()
perturb.warp = noise
noise.phase = seconds * 0.1
perturb.warp = ChainWarp(Ripple(), Swirl())
