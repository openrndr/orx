MultiPassPresetFilter

abstract class MultiPassPresetFilter(passStyles: List<ShadeStyle>) : Filter1to1, PresetFilter(source)

A filter of several passes, each a shade style, with preset slots that every pass reads: like a separable blur, of which both passes read the radius. Make the slots with slot, apply the passes with applyPass, and keep the images between passes in intermediates. The fragment transforms of the passes end with FX_CONTEXT_USE, so that the presets in the slots can read fxContextLibrary.
