EffectChain
Link copied to clipboard
class EffectChain(stages: List<EffectStage> = emptyList()) : Filter1to1

A filter that applies stages in order. Consecutive warp, color and source stages are fused into a single pass that reads the input once, filter stages run as passes of their own. A source stage replaces the image, the stages before it have no effect. A sample stage reads the image as it is after the stages before it, it starts a pass that reads the input with the sampler. The result is that of applying the stages one after another, without resampling between fused stages.
