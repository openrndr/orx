class SVGAnimation

The animation of a composition that is loaded from an SVG document: its SMIL animation elements, CSS animations, rules for :hover and :active, and CSS transitions. update sets the values of the composition at a time; listenTo connects it to the pointer, for events that SMIL animations begin or end with and for pointer states.

svgShape
Link copied to clipboard
fun svgShape(svgPath: String): Shape

Creates a Shape from SVG path data, the value of the d attribute of a path element, like svgShape("M 10 10 h 80 v 80 h -80 z"). All commands are supported, absolute and relative: M, L, H, V, C, S, Q, T, A and Z. Every subpath becomes a contour, closed when it ends with Z. Path data that is not valid is read up to the first error, as SVG does.
