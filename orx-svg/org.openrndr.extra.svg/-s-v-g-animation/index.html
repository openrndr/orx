SVGAnimation

class SVGAnimation(source)

The animation of a composition that is loaded from an SVG document: its SMIL animation elements, CSS animations, rules for :hover and :active, and CSS transitions. update sets the values of the composition at a time; listenTo connects it to the pointer, for events that SMIL animations begin or end with and for pointer states.

Composition.evaluate advances the time of the document with the time of the program: pause, play, seek and playbackRate control it. The events of transitions, of CSS animations and of SMIL animations tell when they start, repeat and end.

val composition = loadSVG("animated.svg")
composition.animation?.listenTo(CompositionInteraction(composition).apply { listenTo(mouse) })
extend {
    composition.evaluate(seconds)
    drawer.composition(composition)
}
