CompositionInteraction

class CompositionInteraction(val composition: Composition)(source)

Interaction with a composition by the mouse, like the pointer events of SVG documents in browsers: entered and exited when the pointer moves onto or off a node and the groups it is in, pressed, released and clicked for the topmost node under the pointer. transform maps the coordinates of the composition to those of the mouse, the transform the composition is drawn with.

val interaction = CompositionInteraction(composition).apply { listenTo(mouse) }
interaction.clicked.listen { println("clicked ${it.node.id} ${it.link}") }
