Hyphenator

class Hyphenator(val patternSet: HyphenationPatternSet, val leftMin: Int = patternSet.leftMin, val rightMin: Int = patternSet.rightMin)(source)

A hyphenator based on Frank Liang's pattern algorithm as used by TeX, with the patterns of hyph-utf8.

Use Hyphenator.forLanguage to find a hyphenator for a language, or the top level hyphenate function.

Parameters

patternSet

the patterns to use

leftMin

the minimum number of characters before a hyphenation point

rightMin
