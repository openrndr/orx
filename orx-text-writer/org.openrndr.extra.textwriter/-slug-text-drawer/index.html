SlugTextDrawer

class SlugTextDrawer(boundaryDrawer: BoundaryDrawer? = null) : TextDrawer(source)

Draws text with a BoundaryDrawer, which draws glyphs from their outlines.

Parameters

boundaryDrawer

the boundary drawer that draws the text, for example a org.openrndr.draw.slug.SlugDrawer, or null for the boundary drawer of the drawer of the active program. The boundary drawer is used from the first time glyphs are added on.
