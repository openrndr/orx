TextComposer

class TextComposer(initialStyle: TextStyle = TextStyle())(source)

A DSL for composing styled text into a list of TextSpans.

The composer holds a current style; every TextStyle property is exposed as a mutable property that changes the current style. Text added with text or line is captured as a span using the current style. Use styled or span to change the style in a nested scope only; the style is restored when the scope ends.

Properties left null are not set by the composer, they will be resolved by cascading onto the style of the drawer or typesetter that consumes the spans.

val spans = composeText {
    face = myFace
    text("CO")
    span("2") {
        sizeInEm = 0.5
        baselineShiftInEm = -0.25
    }
    styled {
        fill = ColorRGBa.PINK
        text(" is a gas")
    }
}
