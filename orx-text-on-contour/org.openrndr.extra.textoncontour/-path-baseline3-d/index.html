PathBaseline3D

class PathBaseline3D(val path: RectifiedPath3D, up: Vector3 = Vector3.UNIT_Y, val offset: Double = 0.0) : TextBaseline(source)

The baseline for text along a 3D path: the 3D counterpart of org.openrndr.extra.textwriter.ContourBaseline.

The text stands in the frames of PosePath3D along the path, which start with their y-axis along up and turn as little as possible, so the text does not twist. A glyph's x runs along the path, its ascenders point along the y-axis of the frame of the path (up, as far as the path allows), and its face looks along the x-axis of that frame, the z-axis x × y of the glyph. offset moves the baseline towards the ascenders. Distances are measured along the path.

Parameters

path

the rectified path

up

the up of the first frame, see PosePath3D

offset

the distance of the baseline from the path, towards the ascenders
