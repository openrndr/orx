MiniGUI

open class MiniGUI(appearance: GUIAppearance = GUIAppearance(), defaultStyles: List<StyleSheet> = defaultStyles(), controlWidth: Int = 150) : GUI(source)

A compact version of GUI that shows a single horizontal bar at the bottom of the screen. A dropdown on the left selects the compartment to show, the controls of that compartment are laid out horizontally next to it, followed by the toolbar when showToolbar is set.

Objects are added and removed like with GUI, parameter values are persisted and saved in the same way.

Parameters

appearance

the base color of the bar; GUIAppearance.barWidth is not used

controlWidth

the width of every control in pixels
