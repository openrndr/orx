GUILayout
Link copied to clipboard
typealias GUILayout = GUILayoutScope.() -> Unit

Builds the element tree of a GUI. The layout arranges the building blocks offered by GUILayoutScope inside GUILayoutScope.body, with containers created using the regular div {} builder. A layout must call GUILayoutScope.sidebar exactly once, as the sidebar holds the compartments of the GUI.

open class MiniGUI(appearance: GUIAppearance = GUIAppearance(), defaultStyles: List<StyleSheet> = defaultStyles(), controlWidth: Int = 150) : GUI

A compact version of GUI that shows a single horizontal bar at the bottom of the screen. A dropdown on the left selects the compartment to show, the controls of that compartment are laid out horizontally next to it, followed by the toolbar when showToolbar is set.
