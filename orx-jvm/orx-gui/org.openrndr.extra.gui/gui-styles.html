guiStyles

fun guiStyles(appearance: GUIAppearance = GUIAppearance()): List<StyleSheet>(source)

The style sheets for the elements of a GUI, in addition to the default control styles.

The selectors refer to the element classes used by the building blocks of GUILayoutScope: fullscreen, container, toolbar, collapse-border, sidebar, compartment, full-canvas, and the collapsed and randomize-strong state classes. A custom GUILayout can use these classes on its own elements, and custom style sheets can be appended to (or replace) the list returned here, see GUI.styles.

Parameters

appearance

the base color and bar width to derive the styles from
