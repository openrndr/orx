suspend fun ControlManager.confirm(message: String, title: String? = null, confirmLabel: String = "OK", cancelLabel: String = "Cancel", destructive: Boolean = false): Boolean

Asks to confirm message like the confirm that takes a callback, and suspends until the dialog closes: true when it is confirmed, false when it is cancelled. Cancelling the coroutine closes the dialog. For use in a coroutine on the thread of the program, like one that launch starts.

fun ControlManager.confirm(message: String, title: String? = null, confirmLabel: String = "OK", cancelLabel: String = "Cancel", destructive: Boolean = false, onResult: (Boolean) -> Unit): Dialog

Asks to confirm message in a modal dialog, under title when it is set, with the buttons cancelLabel and confirmLabel. onResult is called once, when the dialog closes: with true when it is confirmed, false when it is cancelled, by its button, escape, a click on the backdrop or Dialog.close. Enter presses the button with the keyboard focus, which starts on the confirming button, or on the cancelling one when the action is destructive.

popover
Link copied to clipboard
fun ControlManager.popover(anchor: () -> Rectangle?, vararg classes: String, side: PopoverSide = PopoverSide.BELOW, dismissable: Boolean = true, group: String? = null, focus: Boolean = false, init: Div.() -> Unit): Popover

Shows a popover that init builds, next to the area of the window that anchor gives in every frame, on side of it, or on the other side when it does not fit there, and moved along the side to stay inside the window; while anchor gives null it is hidden. It is not modal: the rest of the panel keeps working. When it is dismissable a press outside it and outside the anchor, or escape, closes it. Opening a popover of a group closes the other one of that group. With focus, the keyboard focus moves to its first control; the focus leaves it when it closes.
