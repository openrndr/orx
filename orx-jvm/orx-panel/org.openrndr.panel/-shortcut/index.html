Shortcut

data class Shortcut(val key: String, val modifiers: Set<KeyModifier>)(source)

A keyboard shortcut: key is the name of a key, like k, f5 or escape, held with modifiers. Written as mod+shift+k, where mod is command on macOS and control elsewhere, cmd, ctrl, alt and shift the others.
