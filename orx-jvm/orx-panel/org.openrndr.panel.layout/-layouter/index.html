Layouter

class Layouter(source)

Computes the styles of a tree of elements and lays it out.

Layout happens in two kinds of steps. Measuring determines the size an element wants for a given containing size, it does not change any state, its results are cached for the duration of a layout pass. Arranging sets the sizes and positions of the children of an element, using the measured sizes. Every element in the flow is sized and positioned by its parent, fixed and absolute elements size and position themselves.

Sizes are border-box sizes: they include the padding and the border, but not the margins of an element. Percentages are taken of the content size of the containing element; margins and padding are always taken of its width.
