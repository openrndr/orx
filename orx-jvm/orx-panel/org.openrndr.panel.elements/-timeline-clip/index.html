TimelineClip

data class TimelineClip(val track: Int, val start: Double, val duration: Double, val label: String = "", val color: ColorRGBa? = null, val tag: Int = 0, val fadeIn: Double = 0.0, val fadeOut: Double = 0.0)(source)

a clip of a ClipTimeline: on the track at index track, from start for duration seconds; label and color are how it is shown, the accent of the timeline when null, tag is the host's, like the number of a scene, and is kept as it is; fadeIn and fadeOut are the seconds it fades in over at its start and out over at its end
