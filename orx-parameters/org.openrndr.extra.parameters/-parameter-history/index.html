ParameterHistory

class ParameterHistory(val bindings: ParameterBindings, val maxSteps: Int = 100, clock: () -> Double = { System.nanoTime() / 1E9 })(source)

The history of the changes to the values of bindings, for undo and redo. Changes that come in quick succession are one step: the changes of a drag of a control to the same parameter, and the changes that are made at once, like by ParameterBindings.randomize or ParameterBindings.load.

Parameters

maxSteps

the most steps that are kept

clock

the time in seconds, real time by default
