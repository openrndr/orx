ParameterBindings

class ParameterBindings(source)

The parameters of objects, bound by labels: their values are read, set, randomized, saved and loaded by the label of an object and the name of a parameter. This is what a GUI shows, without a GUI: programs that run without one, and other front ends, like remote controls or MIDI controllers, use it in the same way.

Objects are added with add, under a label that is unique. The objects held by properties with a NestedParameter annotation are bound too, labeled <label of the parent>/<label of the nested parameter>; when such a property holds another object, rebindNested binds that object.

val bindings = ParameterBindings()
val settings = bindings.add(Settings(), "settings")
bindings.load(File("parameters.json"))
bindings["settings", "radius"] = 20.0
